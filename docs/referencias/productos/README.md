## Consecuencias para el diseño (propuesta)

- Distinguir familia/modelo, referencia o variante comercial y unidad física con NFC propio. La ficha 630 contiene varias referencias con diferentes capacidades y dimensiones.
- Un documento puede cubrir varios modelos: el manual 630 incluye también la serie 650 y el manual de garras incluye varios modelos.
- Separar documentos comunes de documentos propios de una unidad. La página de la serie 630 indica que cada polipasto se entrega con un certificado de prueba donde consta el número de serie; ese certificado individual no se ha descargado.
- Registrar idioma, revisión y aplicabilidad de los documentos. No asumir que el último PDF público corresponde a todas las unidades históricas.
- Ficha de unidad propuesta: identificación y fotografía, modelo/referencia, características de la variante, documentación aplicable y descarga offline. Los datos de ejemplo de clientes, NFC o números de serie deberán marcarse como ficticios.

Estos archivos son referencias para el diseño, no un catálogo importado ni documentación validada para una unidad concreta. No se han extraído planos de montaje independientes.
